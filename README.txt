HISABMATE — SIMPLE PERSONAL FINANCE WEB APP

HOW TO RUN
1. Download and extract this ZIP.
2. Open the hisabmate-v2 folder.
3. Double-click index.html. It works in Chrome, Edge, Firefox or Safari.
4. No installation or coding commands are required.

HOW TO PUBLISH ON GITHUB PAGES
1. Upload index.html, style.css and app.js into the root of your GitHub repository.
2. Commit the changes.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to publish your site.

FEATURES
- Simplified dashboard with quick actions
- Add income and expenses using a clear form
- Search and filter transactions
- Category budgets with progress bars
- Savings goals and contribution tracking
- Bill list with paid/pending status
- Monthly report and CSV export
- Backup, restore sample data and clear data
- Mobile responsive layout
- PKR currency

IMPORTANT
This is a front-end starter app. Data is saved only in the current browser on this device.
It has no login, cloud database, multi-device sync, AI assistant, automatic reminders, bank connection
or shared family accounts yet. Do not enter passwords, bank credentials or highly sensitive data.
For a real public multi-user product, add secure authentication, a database, server-side access controls,
backups and a privacy/security review. Sample entries are for demonstration; replace them with yours.
